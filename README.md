# 📋 Attendance System

A simple attendance management project developed to practice application development and attendance-related functionality.

---

## 📌 About the Project

**Attendance System** is a basic project created to manage and maintain attendance records in a simple and organized way.

The project was developed as a learning project to understand application logic, data handling and basic attendance management concepts.

---

## ✨ Features

- 📋 Attendance management
- 👤 Student/participant attendance records
- 📊 Basic attendance tracking
- 🗂️ Organized attendance data
- 🖥️ Simple and easy-to-use application
